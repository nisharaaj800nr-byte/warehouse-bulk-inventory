# Upgrades — 19 Oct 2026

Branch `feat/upgrades-phase1` · 5 commits on top of `main` (`13db23e`).

## 1. Dashboard

- Distribution charts are real Recharts visuals: status / status-bucket / top brands as horizontal bars, age bucket as a donut.
- The portal now parses **both** backend row shapes (Apps Script sheet shape and the local bridge shape) for recent runs, recent errors and the ageing trend. Previously the local backend rendered misaligned columns and an empty trend.
- The local bridge dashboard action also returns `byStatusBucket` and `topBrands`.

## 2. Inventory

- Search, filters and page size persist in `localStorage`; named filter presets are available from the **Views** menu.
- The barcode column can no longer be hidden.
- The item drawer shows a **history timeline** powered by the stock movement ledger.

## 3. Labels

- Label size presets (50×25, 38×25, 60×30 mm), 2–4 print columns, barcode height and field toggles.
- Settings persist per device and apply to both the preview and `@media print` output.

## 4. Sessions & audit

- New **Sessions & Audit** page (ADMIN): active sessions, per-session sign-out, per-user sign-out-all, and the last 100 authentication events with IP.
- Bridge actions: `auth.sessions`, `auth.revokeSession`, `auth.revokeSessions`, `auth.loginHistory`.

## 5. Import rollback

- Every commit snapshots the pre-import state of each touched barcode (`import_snapshots`).
- Rolling a job back restores updated rows, deletes rows the job created, and refuses a second rollback.
- Available as `POST /api/imports/:id/rollback` and bridge action `import.rollback`, plus a **Roll back import** action in the Imports UI.

## 6. Scheduled reports

- New **Scheduled reports** page (MANAGER+ to view, ADMIN to change).
- Schedules store group-by, filters, frequency (daily/weekly/monthly), format (PDF/XLSX) and recipients.
- The server checks every 30 minutes and on boot; each schedule keeps `last_run_at` so restarts never double-send.
- Uses the existing SMTP settings; unconfigured SMTP returns an actionable error.

## 7. Two-factor authentication

- TOTP (RFC 6238, SHA-1, 6 digits, 30s) implemented with Node crypto — no new dependency.
- Enable from **Settings → Two-factor authentication**: scan/paste the setup URI, confirm a code, then save the one-time recovery codes.
- Login asks for the code only when the account has 2FA enabled; recovery codes are single-use.
- Admins can reset another user's 2FA (`auth.totpReset`).
- Central password policy: at least 10 characters, letters and numbers, applied to every create/reset/change/bootstrap path.

## 8. Purchasing (vendors and purchase orders)

- New **Purchasing** page (MANAGER+): vendor master data plus purchase orders with line items.
- Order lifecycle: `DRAFT → ORDERED → PARTIAL → RECEIVED` (or `CANCELLED`).
- Receiving validates remaining quantities, updates the order status automatically and writes inventory rows when a line carries a barcode (source `PURCHASE`, status `IN_STOCK`).
- Vendors with purchase orders cannot be deleted; received orders cannot be edited or cancelled.

## 9. AI assistant

- The local bridge now implements `ai.command` (it was Apps Script-only, so the page failed on the local backend).
- Deterministic Hindi/English parser handles counts, lists and summaries with brand/location/status/age filters.
- Optional LLM planner: set `LLM_API_URL`, `LLM_API_KEY` and `LLM_MODEL` in Settings. Any failure falls back to the deterministic parser, so the assistant never depends on a network call.

## 10. Docker

- `inventory-automation/Dockerfile` builds the portal and server in two stages and serves the built portal from `server/public`.
- `inventory-automation/docker-compose.yml` runs the app on port 5000 with a named volume for the SQLite database.
- Not build-verified in this environment: the local Docker daemon (colima) was not running.

## 11. i18n and encoding

- Shared primitives (buttons, page titles, table headers, card titles, field labels, stat cards, empty states) translate automatically.
- ~60 Hindi/Gujarati entries added; the language selector now renders the native scripts.
- Repaired double/triple-encoded UTF-8 across the portal.
